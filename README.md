A standalone GitHub-compatible git forge in a single Python file (standard library only, no git binary): git smart HTTP with upload-pack protocol v0/v2 and receive-pack, the REST v3 API (repositories, contents, issues, pull requests with squash merges), GraphQL v4, and an MCP endpoint — all over one in-memory store.

## Run it

```sh
MAKEFUN_ENV_URL=<platform env url> MAKEFUN_SHOP_TOKEN=<shop token> python3 main.py
```
